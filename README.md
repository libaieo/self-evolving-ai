# 자가혁신 시스템

AI가 요청을 해석하고, 결과를 검증하며, 개선점을 기록해 다음 작업에 활용하도록 만드는 모듈형 시스템입니다.

## 핵심 설계 문서
- [전체 아키텍처](docs/architecture.md)
- [개발 로드맵과 단계 정의](docs/development-roadmap.md)
- [설계 결정 기록](docs/decisions.md)

## 개발 원칙
- 단계별 구현과 테스트
- 근거 기반 검증 및 자기교정
- 지식 환류와 기억 활용
- 중요한 변경은 사용자 승인
- API 키와 비밀번호는 저장소에 기록하지 않음

## 현재 진행 상태
- **1단계: 완료** — 기본 문서와 저장소 구조를 구성했습니다.
- **2단계: 구현 중** — Python 실행 진입점, 단위 테스트, 설치 안내, 자동 테스트 워크플로를 추가했습니다. GitHub Actions 결과 확인 후 완료 여부를 확정합니다.

단계별 완료 조건은 개발 로드맵을 기준으로 판단합니다.
