# 3단계 — 요청 해석 및 작업 계획

## 목표
사용자의 자연어 요청을 목표, 제약, 성공 조건, 모호성, 우선순위, 위험 수준으로 구조화하고 기본 작업 계획을 생성한다.

## 이번 구현 범위
- `RequestAnalysis`: 분석 결과를 담는 자료 모델
- `TaskPlan`: 단계별 계획과 완료 체크리스트를 담는 자료 모델
- `analyze_request()`: 규칙 기반 요청 분석
- `create_plan()`: 분석 결과에 따른 결정론적 계획 생성
- `--analyze` CLI 옵션: 분석 결과를 JSON으로 출력
- 테스트: 빈 요청, 제약 추출, 위험 표시, 긴급도, 계획 생성, 모호성 표시

## 실행 예시
저장소 루트에서 패키지를 설치한 뒤 다음 명령을 실행한다.

```bash
python -m pip install -e .
python -m self_evolving_ai.main --analyze "한국어로 간단히 설명하고 출처를 포함해 주세요"
```

출력은 `analysis`와 `plan` 두 부분을 가진 JSON이다.

## 중요한 한계
- 이 버전은 키워드 기반 규칙을 사용하며 대규모 언어 모델을 호출하지 않는다.
- 짧거나 지시 대상이 불분명한 요청을 완벽하게 이해하지 못할 수 있다.
- 위험 키워드 감지는 안전 검증의 대체물이 아니다. 실제 외부 작업은 별도의 권한 확인과 승인 정책이 필요하다.
- 현재 단계에서는 작업 계획을 생성할 뿐, 그 계획에 있는 작업을 자동 실행하지 않는다.

## 완료 조건
- 분석 결과가 구조화된 형식으로 출력된다.
- 모호성과 고위험 키워드가 표시된다.
- 자동 테스트가 통과한다.
- 알려진 한계가 문서화된다.
